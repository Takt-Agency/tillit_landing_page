# tillit_landing_page

Landing page officielle de **TilliT** — l'application mobile française de prêt entre proches.

> « Simple entre nous » · La finance qui préserve les liens.

## Stack

- Vite + React 18 + TypeScript
- CSS Modules (charte TilliT : violet `#8B63E8`, corail `#EF8068`, crème `#FBF7F2`)
- Font Awesome 6 (via CDN)
- Google Fonts : Quicksand + Nunito

## Développement

```bash
npm install
npm run dev      # démarre Vite sur http://localhost:5173
npm run build    # build de production
npm run preview  # prévisualise le build
```

## Sections

- Navbar sticky (pill flottante) + logo
- Hero (violet) avec mockup téléphone + social proof
- Bandeau statistiques (compteurs animés au scroll)
- Le problème (3 cartes : flou, silence, gêne)
- Comment ça marche (timeline 4 étapes + mockup interactif)
- Tarifs (NOTE gratuit / ZEN premium avec paliers)
- Avis clients (carousel + bannière de stats)
- CTA final (App Store + Google Play)
- Footer complet avec disclaimers légaux
- Assistant chat flottant avec mascotte
